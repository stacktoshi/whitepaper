# The Bitcoin Whitepaper — narrated, interactive edition

An interactive, narrated edition of Satoshi Nakamoto's 2008 paper *"Bitcoin: A
Peer-to-Peer Electronic Cash System"*, in 15 languages (English, Spanish,
Chinese, Japanese, Korean, French, German, Portuguese, Russian, Arabic, Italian,
Hindi, Polish, Dutch, Hebrew) with per-language text-to-speech narration, right-to-left
and CJK typography, dark mode, a cinematic poster reading mode, a serial reader
mode, and full offline-capable PWA packaging.

**Live:** https://bitcoinwhitepaper.art

## How it works

Everything is one self-contained HTML document (`index.html`) — layout,
typography, figures (animated SVG scenes), the camera system, narration sync and
the i18n layer — deployed as a **static site** (Cloudflare Pages): the document
at `/`, all assets under `whitepaper/*`, and one narration MP3 per language and
narrator, streamed straight from the pack with HTTP Range support.

- **Text**: the paper body per language comes from official bitcoin.org PDF
  translations, compiled into packs by `scripts/i18n/build-locale.mjs`
  (structure-validated against the English reference; token alignment is
  hash-checked — the English token stream signature must never change).
- **Narration**: per-language TTS generated by `scripts/build-narration.mjs`
  (Inworld TTS-2); each pack ships a narration MP3 plus a cue table mapping
  words to audio offsets.
- **Figures**: hand-built animated SVG scenes (coin, P2P network, trust,
  transaction chain, timestamp server, proof-of-work, incentives) that step in
  sync with the narration.

## Development

Open `index.html` via any static file server (the app fetches its packs and
audio relative to the document), e.g.:

```sh
npx serve .
```

## Deploy (Cloudflare Pages)

- **Build command:** `pnpm run build` (stages `dist/`: `index.html` + `whitepaper/` assets)
- **Build output directory:** `dist`
- Every push to `main` deploys automatically.

The app fetches its packs and audio relative to the document, so the deployed
tree must be exactly `index.html` + `whitepaper/*` — which the build command
assembles.
