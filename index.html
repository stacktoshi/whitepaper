About

The layout and typography of this edition take inspiration from Daily Coin Post’s free high-quality Bitcoin whitepaper poster.

BitcoinWhitepaper.online is an independent provenance record for the four known versions of the Bitcoin whitepaper — the lost August 2008 draft, the surviving 3 October 2008 draft, a January 2009 copy known only through the COPA v Wright court record, and the canonical 24 March 2009 file embedded in the block chain at block 230,009. It identifies any copy in seconds through plain-text tests — citation numbering, section text, PDF structure and embedded font subsets — and ships standard-library Python scripts that carve and verify the canonical bytes straight from the block chain. Its dating rests on content rather than file metadata: a citation the author had only just learned to make, and a transaction-fee paragraph that did not exist yet.

This narrated edition is open source — github.com/stacktoshi/whitepaper · live at bitcoinwhitepaper.art.
